# Security policy

Do not open a public issue for a suspected disclosure of private deployment
information, credentials, or personal data. Use GitHub's private vulnerability
reporting for this repository.

cnix publishes from a generated allowlisted projection, not from a mixed
private/public Obsidian vault. A successful website build is not a security
verdict: publication also requires the guardian checks described in
[`knowledge/system/publication-guardian.md`](knowledge/system/publication-guardian.md).
