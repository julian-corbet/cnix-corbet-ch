# cnix

Corbet Nix knowledge compiler: public documentation, safe examples, and a human-
and machine-readable website generated from one Markdown corpus.

Start with [`knowledge/index.md`](knowledge/index.md). Contributors can run
`npm ci` followed by `npm run check`. Maintainers publish with `npm run deploy`,
which requires an independent, structured privacy verdict for the exact static
artifact before the hosting provider receives it. Publication also requires the
Nix CLI to provide the immutable, content-addressed upload source.
