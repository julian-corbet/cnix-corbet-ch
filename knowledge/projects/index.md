# Corbet Nix projects

Each project receives one concise technical page: summary, definition,
mechanism, configuration, tutorial, evidence and limits, and related projects.
The same reviewed project concept generates a distinct marketing showcase at its
`nix*.corbet.ch` hostname. This index is the searchable map of the complete
suite, not a filesystem listing or a giant navigation dropdown.

See [Project showcases](../system/project-showcases.md) for the boundary between
the technical reference and the landing page.

Project extraction is tracked as
[source drift ingestion](https://github.com/julian-corbet/cnix-corbet-ch/blob/main/TODO.md#cnix-0004--source-drift-ingestion).
