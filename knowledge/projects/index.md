# Corbet Nix projects

Each project receives one concise public page: summary, definition, mechanism,
configuration, tutorial, evidence and limits, and related projects. This index
is a curated map, not a filesystem listing.

Project extraction is tracked as
[source drift ingestion](https://github.com/julian-corbet/cnix-corbet-ch/blob/main/TODO.md#cnix-0004--source-drift-ingestion).
